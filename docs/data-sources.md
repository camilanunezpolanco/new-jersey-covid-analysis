# Data Sources

The following sources are cited in the original report and presentation. This is a record of those references, not a verified download manifest. Original input files, exact extraction dates, and the complete preparation workflow have not been recovered.

| Subject | Cited source |
| --- | --- |
| COVID-19 cases and deaths | [New York Times COVID-19 data repository](https://github.com/nytimes/covid-19-data) |
| Demographic characteristics | U.S. Census Bureau, ACS 2019-2023 five-year estimates, [table DP05](https://data.census.gov/table/ACSDP5Y2023.DP05) |
| Transportation and commute times | U.S. Census Bureau, ACS 2019-2023 five-year estimates, [table B08134](https://data.census.gov/table?q=table+B08134) |
| Internet subscriptions | U.S. Census Bureau, ACS 2019-2023 five-year estimates, [table B28002](https://data.census.gov/table/ACSDT5Y2023.B28002) |
| Uninsured rates | [Census Small Area Health Insurance Estimates (SAHIE)](https://www.census.gov/data-tools/demo/sahie/) |
| Hospital capacity | [American Hospital Directory: New Jersey](https://www.ahd.com/states/hospital_NJ.html) |
| Population density | [New Jersey Demographics](https://www.newjersey-demographics.com/counties_by_population), as cited in the report |
| Unemployment | [Focus NJ: Pandemic Redefined High Unemployment](https://focusnj.org/economic-trends/pandemic-redefined-high-unemployment) |
| Median household income | NorthJersey.com, "New Jersey's wealthiest counties ranked by median household income," November 29, 2024, as cited in the report |

The full bibliography is on page 13 of the [report](../reports/project-report.pdf) and slide 21 of the [presentation](../reports/presentation.pdf). These links identify cited sources; their current contents have not been checked for equivalence with the original inputs.
